# Boba Match

A single-page, six-language (中文 / English / Tiếng Việt / ไทย / 日本語 / 한국어) bubble tea matcher for visitors to Taiwan.

Answer 7 questions (experience, mood, weather, temperature, sweetness, topping, dietary needs) and get a recommended drink, a Chinese order card to show the staff, brand suggestions, and an ordering guide.

No build step: open `index.html` in a browser.

Brand descriptions are general introductions and are not verified or sponsored. Menus vary by shop.
